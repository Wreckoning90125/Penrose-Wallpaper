# Platform documentation

Local notes for Android, Gradle, NDK, Kotlin, Vulkan, and CI behavior that
affect this app's build or renderer. These files are not tiling-theory docs;
they exist so version-sensitive platform decisions are easy to refresh.

| File | Scope |
|------|-------|
| [`android-vulkan.md`](android-vulkan.md) | Android/AGP/NDK/Kotlin/Vulkan version pins, official update sources, and repo-specific build notes |
| [`control-graph-regressions.md`](control-graph-regressions.md) | Web control graph and renderer regression rules for sliders, layout, IO handles, transport, and material behavior |
| [`dev-build.md`](dev-build.md) | Web dev server, local quality gate, WSL2 validation, and Android build/signing commands |
